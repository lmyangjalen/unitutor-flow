# 备课与课堂质量检查清单

## 备课前
- [ ] 有学情依据而不是凭印象。
- [ ] 最多两项可测教学目标。
- [ ] 教师答案与学生讲义分开。
- [ ] 原创题标明来源，答案已人工复核。
- [ ] 课堂时长包含学生独立练习和短暂休息。
- [ ] 考虑学习偏好但不对学生贴固定标签。

## 课堂中
- [ ] 学生能尝试并解释自己的解题思路。
- [ ] 区分独立、提示后、未完成。
- [ ] 不羞辱错误，不用比较制造压力。
- [ ] 如难度或节奏不适合，及时调整。

## 课后
- [ ] 留有明确的小测或课堂表现证据。
- [ ] 家长反馈具体、真实、符合沟通偏好。
- [ ] 记录知识状态及下次复测。
- [ ] 画像中的事实与假设分开。
- [ ] 不把当堂完成说成持续进步。
