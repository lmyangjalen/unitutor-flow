# 费用与家长沟通规范

接单估算：课时收入 = 双方约定单价 × 实际/预估授课时长；总时间应考虑往返交通、备课及课后反馈；若材料齐全，可算净时薪=(收入-老师承担交通等确认成本)/总占用时间，缺少变量时只给公式/范围，不编造。

每次课后：应计金额并不等于到账金额。若未明确按次结算还是按周结算，则只能提示老师询问约定，不能催。未到期不用提示家长付款。确认已到付款日期、金额核对且仍未收到时，可准备如下**可选**一句话，由老师亲自发送：

“另外，按照咱们之前约定，这阶段【X次/实际X小时】课时费合计【X元】，您方便的时候帮忙核对一下结算就行，谢谢您！”

每次家长反馈必须是真实的教学情况：“今天学了什么 → 孩子能独立做什么 → 还需努力的点 → 下次计划”，可适当肯定可验证的努力、思考和参与，不夸大、不贬低孩子，不把“情绪价值”变成心理操控。
