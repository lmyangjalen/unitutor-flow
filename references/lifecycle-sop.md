# 工作流 SOP

1. **接单评估**：对比老师自身经验、科目难度、预估通勤/备课时间和费用。输出接单建议、第一条家长微信、待确认问题、匿名档案草稿。
2. **沟通变更**：从家长和孩子新的描述更新外部档案与当前目标。保留“已确认事实/待验证原因/未对齐期望”。
3. **试课准备**：生成分钟级教师教案、教师上课引导词、学生版原创诊断题/讲义（无答案）、教师版答案解析、课堂观察表。学生没上课前不得写“今天取得进步”。
4. **正式备课**：阅读前次错题和课堂总结，设计最多两项目标，包含复习—演示—独立训练—迁移—离堂测。教材不清晰时不得编造页码。
5. **每次上课后**：默认交付课堂总结、家长微信、费率/结算核对、下节课方向、学生档案更新、风险或进展提醒；家长微信是必交项。
6. **3–5 次课阶段复盘**：对照可比证据判断进展，给有理由的下一阶段课时建议，尊重家长和学生继续、调整或停止选择。
