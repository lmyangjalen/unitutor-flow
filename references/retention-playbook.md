# 长期合作与续课工作手册

核心逻辑：教学价值 → 可验证进步 → 可靠沟通 → 长期信任 → 家长自愿续课。不是靠推销话术制造依赖。

## 节奏
- **试课前**：对齐目标、教学方式、可验证的近期结果、反馈频率与双方现实约束。
- **第 1–2 次**：验证基础和学生学习互动偏好，允许调整目标。
- **每次课后**：提供简短、有具体证据的反馈；内部记录独立与提示后完成的区别。
- **每 3–5 次课**：同类任务复测，报告已取得的进展、局限和未解决的问题。
- **续课前**：说明下一周期的可测目标、建议课时及原因，并允许继续、调整、暂停或退出。

## 留存风险与诚实处理

| 信号 | 先核实 | 行动 |
|---|---|---|
| 家长质疑效果 | 基线、评估方式和预期是否一致 | 对照证据，约定短周期复测 |
| 学生抵触 | 难度、课程节奏、关系和目标 | 征询学生意见，调整方法 |
| 家长回复变少 | 时间、消息长度及有无疑问 | 简短确认沟通偏好 |
| 经常取消课程 | 时间表是否适配 | 调整时间或暂停 |
| 看不到明显变化 | 测量是否合理、教学法是否有效 | 复核诊断；必要时建议其他方式 |
| 续课待定 | 是否需要更多信息 | 提供透明计划，尊重决定 |

### 续课沟通原则
基于事实回顾课程 → 如实说明当前证据和未解决点 → 提出可测的下一阶段计划 → 询问家长是否愿意继续。禁止保证分数、虚假紧迫感、羞辱或施压。若课程不再适合，建议停止合作。
